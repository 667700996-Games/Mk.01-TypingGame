# 애국가 타자연습

애국가 1절부터 4절까지를 한 소절씩 정확하게 입력하며 연습하는 데스크톱 타이핑 게임입니다. 태극의 두 색과 절제된 한국어 중심 화면을 사용해 기존 프로젝트의 정체성을 유지하면서, 실제 연습에 필요한 흐름과 기록을 갖췄습니다.

## 주요 기능

- 전곡 또는 1~4절 중 원하는 범위 선택
- 글자별 정답·오답 즉시 표시
- 정확도, 분당 글자 수, 경과 시간, 연속 정타 실시간 집계
- 소절과 전체 범위를 함께 보여주는 진행도
- 완주 결과와 같은 범위 재도전
- 연습 범위별 개인 최고 기록 자동 저장
- 한글 입력을 포함한 게임 로직 단위 테스트

## 실행

Go 1.21 이상과 [Fyne의 플랫폼별 필수 도구](https://docs.fyne.io/started/)가 필요합니다. macOS/Linux 관리 실행기는 Python 3.9 이상과 Make를 사용합니다.

```bash
make run
```

테스트는 다음 명령으로 실행합니다.

```bash
make test
```

가사는 [행정안전부 우리나라 국가상징 안내](https://www.mois.go.kr/chd/sub/a05/story/screen.do)에 실린 애국가 1~4절을 기준으로 하며, 타자연습에 맞게 문장부호 없이 소절 단위로 구성했습니다.
