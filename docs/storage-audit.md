## 실행한 정리와 용량

`.DS_Store`는 내용의 `0000000142756431`(Finder Bud1) 헤더, 추적/참조 상태를 확인했다. 삭제 이유는 재생성 가능한 Finder 디렉토리 보기 메타데이터이며, 파일 이름이나 Git 무시 여부가 아니다. 삭제한 논리 크기는 **6,148B**, 할당량은 **8,192B**였다. 삭제 전 해시 및 원시 측정값은 [storage-audit.json](storage-audit.json)에 보관했다.

**정리로 프로젝트 용량은 8KiB 감소했지만, 삭제 직전·직후 `df`가 측정한 여유 공간 증가는 0KiB다.** APFS 할당·스냅샷·백그라운드 쓰기 등이 섞이므로 파일 크기 감소를 실제 여유 공간 증가로 바꾸어 주장하지 않는다. 최종 측정은 아래 기록과 JSON의 `final`을 참조한다.

검증용 개발 압축본 **15,898,522B(15.16MiB)** 1개는 보관한다. 내부 실행 파일은 27,938,386B이며 압축 후 동일한 원시 실행 파일 사본은 제거했다. 실제 테스트/빌드가 기본 Go 컴파일 캐시를 새로 생성했다(약 245MiB, 프로젝트 밖). 재사용 캐시는 매번 지우지 않는다. 따라서 전체 작업 후 프로젝트/디스크 사용량이 늘어난 부분은 검증 산출물·재사용 캐시·추가 관리 코드와 문서에 해당한다. 세션 중 외부에서 Git 커밋이 추가되는 것도 관찰됐으며 `.git` 변화는 별도로 포함된다. 이번 작업에서 Git 정리·커밋·푸시 명령은 실행하지 않았다.

## 보존 확인과 자동화

- 원본 폰트, 전체 Go 코드/테스트, `go.mod`, `go.sum`, LICENSE **9개 파일의 SHA-256이 전후 일치**한다. README는 실행 방법/정리 정책 링크를 의도적으로 변경했다. 원본 게임 기능·에셋 품질·앱 ID·모듈 버전·출시 설정은 변경하지 않았다.
- [scripts/build.py](../scripts/build.py), [Makefile](../Makefile), [CI](../.github/workflows/build.yml)에 실제 실행/정리 경로를 연결했다. 전용 작업 영역, OS 잠금/상속, 자식 시작 게이트, 신호 처리, 다음 실행 회수, 검증 후 원자적 게시, 개발 산출물 2개/로그 10개·1MiB 제한을 적용한다.
- 원격 CI의 개발 패키지는 업로드하지 않으며 진단 로그만 7일 보관한다. 임시 호스팅 러너가 실행 간 상태를 공유하지 않아 원격 로그에는 개수 대신 TTL을 적용했다. [upload-artifact 보관 설정](https://github.com/actions/upload-artifact#retention-period) 참조.
- 보존 규칙과 신규 도구 적용 의무는 [AGENTS.md](../AGENTS.md), 정책/실행/예외 기록 양식은 [build-cleanup.md](build-cleanup.md)에 있다.
